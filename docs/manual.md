# 管理システム 簡易マニュアル

---

## はじめに

本マニュアルは、管理システムの導入から日常業務での活用方法を解説するものです。
**管理者（admin）** と **一般ユーザー（staff）** の2つの視点で構成しています。

### 本システムでできること

| 機能 | 概要 |
|------|------|
| 顧客管理 | 顧客情報の一元管理（連絡先・銀行口座含む） |
| 代理店管理 | 代理店の階層構造・事業別の関係管理 |
| 契約マスタ | 営業案件の進捗・ステータス・カスタムフィールド管理 |
| ムーブメント管理 | 案件ごとの営業プロセス（ステップ）の進捗管理 |
| 代理店支払手数料 | ショット/ストック手数料の自動計算・支払明細書の発行 |
| 収益管理 | 事業ごとの自社取り分の設定と、自社売上・粗利・粗利率の可視化 |
| ダッシュボード | KPI・パイプライン・売上推移・代理店ランキングの可視化 |
| タスク管理 | マイタスク・グループボードでのタスク管理（カンバン・カレンダー） |
| プッシュ通知 | スマホ・PCへのリアルタイムプッシュ通知（iPhone Safari / Android Chrome / PC対応） |
| AIアシスタント | 営業データに対する自然言語での問い合わせ |
| 売上目標・レポート | 月次売上目標の設定と実績レポート |
| 資料共有 | 代理店向けの資料・請求書の配信管理 |
| QA / 問い合わせ | ナレッジベースとサポート窓口 |

### ユーザーの種類

| ロール | 説明 | アクセス範囲 |
|--------|------|-------------|
| admin（管理者） | システム全体の設定・管理が可能 | 全機能 |
| staff（社内スタッフ） | 日常の営業業務を行う | 管理者設定画面を除く全機能 |
| partner_admin（代理店管理者） | 代理店ポータルの管理 | 代理店ポータル + スタッフ管理 |
| partner_staff（代理店スタッフ） | 代理店ポータルの閲覧 | 代理店ポータル（閲覧のみ） |

# 第1部：管理者（admin）向けマニュアル

> **対象読者**: システム管理者。初期設定からマスタ整備、日常の管理業務まで。

---

## 1. システム導入の推奨フロー

新しくシステムを使い始める場合、以下の順番で設定するとスムーズです。

```
Step 1  事業マスタの作成
   ↓
Step 2  事業ごとの詳細設定（カスタムフィールド・ステータス定義・KPI・代理店支払手数料/自社取り分等）
   ↓
Step 3  ユーザーの登録（社内スタッフ + 代理店ユーザー）
   ↓
Step 4  顧客マスタの登録（CSV一括 or 個別登録）
   ↓
Step 5  代理店マスタの登録（階層構造を含む）
   ↓
Step 6  売上目標の設定
   ↓
Step 7  必要に応じてAIアシスタント・通知等のシステム設定
```

以降、各ステップを詳しく説明します。

---

## 2. Step 1：事業マスタの作成

**画面**: サイドバー「事業マスタ」→「新規作成」

事業マスタはシステムの中核です。契約マスタ・ダッシュボード・ムーブメント等、多くの機能が事業に紐づきます。

### 操作手順
1. サイドバーの「事業マスタ」をクリック
2. 「新規作成」ボタンをクリック
3. 以下を入力して保存
   - **事業コード**: 英数字の一意コード（例: `SALES01`）
   - **事業名**: 表示名（例: 「法人営業事業」）

### ポイント
- 事業コードは後から変更できません。慎重に設定してください
- 事業を作成すると、サイドバーの事業セレクターに表示されます
- 契約マスタやムーブメントは事業を選択しないと表示されません

---

## 3. Step 2：事業ごとの詳細設定

**画面**: 事業マスタ詳細画面の各タブ

事業を作成したら、以下の4つの設定を行います。

### 3-1. 案件フィールド設定（カスタムフィールド）

**タブ**: 「案件フィールド設定」

案件（契約マスタ）で管理する項目を自由に定義できます。

| フィールド種別 | 用途例 |
|--------------|--------|
| テキスト | 備考、ニーズ、特記事項 |
| 数値 | 売上金額、台数、面積 |
| セレクト（プルダウン） | 商品種別、ランク |
| チェックボックス | 承認済み、確認済み |
| 日付 | 契約日、納品予定日 |
| 月（YYYY-MM） | 対象月、開始月 |
| URL | 関連資料リンク |
| テキストエリア | 長文のメモ |
| 計算式（formula） | 他フィールドの演算結果（例: `単価 * 数量`） |

**操作手順**:
1. 「フィールド追加」をクリック
2. フィールド名・種類・必須/任意を設定
3. 必要に応じて「代理店に公開」「絞り込み対象」のチェックを設定
4. ドラッグ&ドロップで表示順を変更
5. 保存

**Tips**:
- 「代理店に公開」にチェックすると、代理店ポータルでもそのフィールドが表示されます
- 「絞り込み対象」にチェックすると、一覧画面のフィルターに追加されます
- 計算式フィールドでは `{フィールドキー}` で他のフィールドを参照できます

### 3-2. 営業ステータス定義

**タブ**: 「営業ステータス」

案件の進捗を管理するステータスを定義します。

**操作手順**:
1. 「ステータス追加」をクリック
2. ステータス名（例: 提案、検討中、受注見込み、受注、失注）を入力
3. 表示色を選択
4. 必要に応じて以下を設定:
   - **最終ステータス**: 完了扱い（デフォルトで一覧から非表示）
   - **失注ステータス**: 失注扱い（デフォルトで一覧から非表示）
   - **ソート順**: ステータスの並び順

### 3-3. KPI定義

**タブ**: 「KPI設定」

ダッシュボードで表示するKPIを定義します。

**操作手順**:
1. 「KPI追加」をクリック
2. KPIラベル（例: 売上金額、受注台数）を入力
3. 集計対象のフィールドを選択（カスタムフィールドの数値型）
4. 対象とする営業ステータスを選択（複数選択可）
5. 単位フォーマットを設定（例: `#円` → `1,000円`、`#台` → `100台`）

### 3-4. ムーブメント定義

**タブ**: 「ムーブメント定義」

案件の営業プロセスを段階的に管理するためのテンプレートを作成します。

**操作手順**:
1. 「ステップ追加」でプロセスの各段階を定義
2. ステップ名を入力（例: 初回訪問、提案書提出、見積提出、契約締結）
3. 必要に応じてステップに案件フィールドを紐付け（そのステップで入力/表示するフィールド）
4. ドラッグ&ドロップで順序変更
5. 保存

**Tips**:
- ムーブメント定義を更新すると、既存の案件にも自動で同期されます
- 手動同期ボタンで任意のタイミングでも同期可能です

### 3-5. 代理店支払手数料・自社取り分の設定

**タブ**: 「代理店支払手数料」

代理店に支払う報酬と、取扱高のうち自社の売上になる割合（自社取り分）を設定します。
ここを設定しないと、ダッシュボードの収益セクションと契約マスタの収益列は表示されません。

**用語**:

| 用語 | 意味 |
|------|------|
| 取扱高 | 顧客が支払う総額。案件の金額フィールドから取得します |
| 自社取り分 | 取扱高のうち自社の売上になる割合（率または固定額） |
| 自社売上 | 取扱高 × 自社取り分 |
| 代理店支払手数料 | 代理店に支払う金額（担当代理店＋上位代理店）。税抜で扱います |
| 粗利 | 自社売上 − 代理店支払手数料。粗利率 = 粗利 ÷ 自社売上 |

**ショットとストック**:

| 種別 | 発生タイミング |
|------|---------------|
| ショット | 収益確定時に1回だけ |
| ストック | 契約が継続している間、毎月 |

売上・報酬とも、ストックは解約日（または固定期間）まで毎月計上されます。

**操作手順**:
1. **代理店支払手数料**: ショット/ストックそれぞれに、担当代理店と上位代理店の報酬を設定
2. **基準金額フィールド**: 報酬の率をかける対象フィールドを選択
3. **消費税率・支払い対象月**: 支払明細書の発行条件を設定
4. **自社取り分**: ショット/ストックそれぞれに、率（%）または固定額（円）を設定
5. 保存

**Tips**:
**代理店階層をたどった手数料の積み上げ**:

案件に紐づく代理店から親をたどり、**料率が設定されている段の分を全て合計**します。未記入の段は0として素通りし、さらに上位へ遡ります。

| 階層 | 設定 | 案件に代理店Cが紐づく場合 |
|------|------|--------------------------|
| 代理店A（最上位） | 上位代理店 5% | 5% |
| 代理店B | 担当代理店 10% | 10% |
| 代理店C（担当） | 未記入 | 0% |
| | | **合計 15%** |

| 階層 | 設定 | 案件に代理店Cが紐づく場合 |
|------|------|--------------------------|
| 代理店A（最上位） | 担当代理店 10% | 10% |
| 代理店B | 未記入 | 0% |
| 代理店C（担当） | 未記入 | 0% |
| | | **合計 10%** |

- **代理店が紐づいていない案件（自社直営）は手数料が一切発生しません**。売上がそのまま粗利になります
- 各段は「担当代理店」欄（担当店の場合）または「上位代理店」欄（上位店の場合）を見ます。該当欄が未記入なら、もう一方の欄の値を使います
- 事業デフォルトは**担当代理店にのみ**適用されます。上位店には適用しません（階層が深いほど既定料率が段数ぶん積み上がってしまうため）
- 自社取り分は「事業デフォルト → 案件ごと」の2層です（代理店階層には依存しません）
- 上書きはショット/ストックのスロット単位で効きます。片方だけ上書きしても、もう片方は事業デフォルトのままです
- 率（%）を使う場合、基準フィールドが**金額**であることを確認してください。台数などの数量フィールドを基準にすると、率をかけた結果が金額になりません。その場合は固定額（円）を選ぶか、取り分専用の基準金額フィールドに金額フィールドを指定してください
- 報酬は税抜で粗利から引かれます（消費税は預り金のため）

## 4. Step 3：ユーザー登録

**画面**: ユーザーメニュー → 「ユーザー管理」（admin のみ）

### 社内ユーザーの登録
1. 「ユーザー追加」をクリック
2. 氏名・メールアドレスを入力
3. ロールを選択（admin or staff）
4. パスワードを設定（「自動生成」ボタンあり）
5. アクセスさせる事業を選択（複数可）
6. 保存

### 代理店ユーザーの登録
1. 「ユーザー追加」をクリック
2. 氏名・メールアドレスを入力
3. ロールを選択（partner_admin or partner_staff）
4. 所属する代理店を選択（検索コンボボックスで絞り込み可）
5. パスワードを設定
6. アクセスさせる事業を選択
7. 保存

### ポイント
- 代理店管理者（partner_admin）は、自社の partner_staff をポータルから追加・管理できます
- ユーザー一覧は「階層表示」「フラット表示」の切替が可能です

## 5. Step 4：顧客マスタの登録

**画面**: サイドバー「顧客マスタ」

### 個別登録
1. 「新規作成」をクリック
2. 顧客コード・顧客名・住所・連絡先等を入力
3. 保存
4. 詳細画面で連絡先・銀行口座を追加（タブから操作）

### CSV一括登録
1. 「CSVインポート」をクリック
2. テンプレートをダウンロード（「テンプレートDL」ボタン）
3. テンプレートにデータを入力
4. CSVファイルをアップロード → **ドライラン実行**
5. エラーがあればエラーレポートをダウンロードして修正
6. エラーがなければ「確定」で登録

### ポイント
- ドライランでデータの妥当性を事前確認できます（実データには影響しません）
- 顧客コードは一意です。重複するとエラーになります

## 6. Step 5：代理店マスタの登録

**画面**: サイドバー「代理店マスタ」

### 階層構造について
- 代理店はN次の親子階層を持てます（例: 1次代理店 → 2次代理店 → 3次代理店）
- マスタ階層（全体共通）と事業別階層（事業ごとに異なる親子関係）の2種類があります

### 操作手順
1. 「新規作成」をクリック
2. 代理店コード・代理店名を入力
3. 親代理店を選択 → 階層（Tier）が自動決定されます
4. 保存
5. 詳細画面で連絡先・銀行口座・事業リンクを設定

### ポイント
- 事業別の親子関係は「事業リンク」タブで設定します
- 一覧表示では「スコープ切替」で「マスタ階層」「事業別階層」を切り替えて確認できます

---

## 7. Step 6：売上目標の設定

**画面**: サイドバー「売上目標」（事業選択が必要）

### 操作手順
1. サイドバーの事業セレクターで対象事業を選択
2. 「売上目標」をクリック
3. 対象年度を選択
4. 月別に目標値を入力
5. 保存

### ポイント
- ダッシュボードの「達成率」はここで設定した目標値に対する実績比です
- KPIごとに目標を設定できます

---

## 8. Step 7：システム設定

**画面**: ユーザーメニュー → 「システム設定」（admin のみ）

### AIアシスタント設定
1. OpenAI APIキーを入力（暗号化して保存されます）
2. モデル選択: 自動（推奨）/ GPT-4o / GPT-4o-mini
3. 保存

### プッシュ通知設定
プッシュ通知は環境変数（VAPID鍵）の設定のみで有効になります。管理画面での追加設定は不要です。
ユーザーは通知ベルのポップオーバーから自分で有効化します。

### 資料共有の管理
**画面**: 事業マスタ詳細 → 「資料」タブ / 「明細」タブ

1. ファイルをアップロード
2. ドラッグ&ドロップで表示順を変更
3. 「通知送信」ボタンで代理店に通知（再送も可能）

### お知らせ管理
**画面**: ユーザーメニュー → 「お知らせ管理」

1. 「新規作成」をクリック
2. タイトル・本文・優先度・対象（全体 or 特定事業）を設定
3. 公開日を設定して保存

## 3. ダッシュボード

**画面**: サイドバー「ダッシュボード」

ログイン後に最初に表示される画面です。

### 見方

| セクション | 表示内容 |
|-----------|---------|
| KPIサマリー | 実績値・目標達成率・前月比 |
| パイプライン | 営業ステータス別の件数・金額 |
| 売上推移グラフ | 年度内の月別推移（実績 + 目標ライン） |
| 収益 | 自社売上・代理店支払手数料・粗利・粗利率と、年度の月別推移・案件別の内訳 |
| 代理店ランキング | 代理店別の売上順位 |
| タスク | 期限間近・期限超過のタスク |

**収益セクションの見方**:

| カード | 内容 |
|--------|------|
| 自社売上 | 取扱高のうち自社の売上になる分。カード下部に取扱高を併記 |
| 代理店支払手数料 | 代理店へ支払う手数料の合計（税抜）。内訳は契約マスタの列で確認します |
| 粗利 | 自社売上 − 代理店支払手数料 |
| 粗利率 | 粗利 ÷ 自社売上。カード下部に**取扱高比**（粗利 ÷ 取扱高）も併記します |

- 粗利率は2種類あります。メインの数字は**自社売上比**（一般的な粗利率）、カード下部の小さい数字は**取扱高比**（自社取り分を考慮しない、顧客への請求額に対する参考値）です。案件別内訳・事業別内訳の粗利率にも同様に取扱高比を併記します
- KPIサマリーの「売上」は**取扱高**（顧客が支払う総額）で、自社売上とは別物です。両方を見比べてください
- 集計は**売上KPI（プライマリKPI）と同じ基準**です。同じ金額フィールドを取扱高とし、同じ計上月フィールドで月に割り当て、同じ営業ステータス条件で対象案件を決めます。そのためKPIサマリーの売上と母集団が一致します
- ダッシュボードは**見込みベース**です。支払明細書（代理店支払手数料の締め）は収益確定日を起点とする**確定ベース**のため、両者の数字は一致しないことがあります
- **収益推移グラフは年度（4月開始12ヶ月）**で表示します。上部の売上推移グラフと同じ年度に連動し、年度セレクターを動かすと両方が切り替わります。単月モードのときは選択中の月が濃色で強調されます
- **カードの数字は期間フィルターの合計**です（グラフの年度とは別軸）。単月モードなら当月ぶん、全期間なら全期間ぶんになります
- 全社表示では事業別の内訳テーブルも表示されます
- 事業マスタで自社取り分が未設定の場合、このセクションは設定を促すメッセージになります（→ [3-5](#3-5-代理店支払手数料自社取り分の設定)）
- ここで扱うのは**粗利（売上総利益）**までです。経常利益は販管費・営業外を含む全社の数字のため、事業別・案件別には算出できません

### 操作
- **期間フィルター**: 上部で「単月 / 期間指定 / 全期間」を切替
- **単月ナビ**: 単月モード時に `<` `>` で前月/翌月を移動、「当月に戻す」で今月に戻る
- **KPI切替**: 複数のKPIが定義されている場合、セレクターで切り替え
- **事業切替**: ヘッダーの事業セレクターで全社/事業別を切替

## 4. 契約マスタ（案件管理）

**画面**: サイドバー「契約マスタ」（事業選択が必要）

### 案件の新規登録
1. 「新規作成」をクリック
2. 顧客・代理店をプルダウンで選択
3. 営業ステータスを選択
4. 受注予定月を設定
5. カスタムフィールド（金額、ニーズ等）を入力
6. 必要に応じて「ポータルに表示」チェックを設定（デフォルトON。OFFにすると代理店ポータルに非表示）
7. 保存 → 案件番号が自動採番されます

### 一覧画面の使い方

**フィルター**:
- 営業ステータスで絞り込み（複数選択可）
- 受注予定月で絞り込み（単月 / 範囲指定 / 全件）
- テキスト検索（顧客名・代理店名・案件番号）
- カスタムフィールドのフィルター（管理者が「絞り込み対象」に設定したもの）

**インライン編集**:
- セルをクリックすると直接編集可能（営業ステータス、ポータル表示など）
- ポータル表示はチェックボックスで一覧上から直接ON/OFF切替可能

**列設定**（テーブル表示設定モーダル）:
- ヘッダー右の「列設定」ボタンをクリックすると設定モーダルが開きます
- **基本設定タブ**: 表示件数（10/25/50/100件）を変更
- **列の表示・順序タブ**: 列の表示/非表示切替、ドラッグ&ドロップで並び替え、列名検索、一括選択で複数列をまとめて非表示化、ピン留め設定
- **ソート設定タブ**: ソート列の追加・削除、昇順/降順切替、優先度の並び替え
- 変更は「保存」ボタンで確定します（キャンセルで変更を破棄可能）
- 「デフォルトに戻す」で全設定をリセットできます（確認ダイアログ付き）

**ビューの保存**:
- フィルターや列設定を「ビュー」として保存可能
- タブで保存済みビューを素早く切替
- 「チームに共有」で他のメンバーと共有可能
- ビュー保存後に追加された列は、その列のデフォルト設定に従います（非表示設定の列は自動表示されません）

**CSV操作**:
- エクスポート: 現在の表示条件でCSV出力
- インポート: テンプレートDL → データ入力 → アップロード → ドライラン確認 → 確定

### 報酬・収益の列

列設定の「手数料情報」「収益情報」グループから表示できます（いずれも初期は非表示）。

| グループ | 列 |
|---------|-----|
| 手数料情報 | 収益確定日、解約日、ショット手数料（担当代理店/上位代理店/合計）、ストック手数料（担当代理店/上位代理店/合計）/月 |
| 収益情報 | 自社取り分（ショット/ストック）、自社売上、粗利、粗利率 |

- 金額は**売上KPIの対象ステータス・計上月に合致する案件のみ**表示されます。合致しない案件は自社取り分だけが表示されます
- 案件ごとの取り分を上書きしている場合、「15%（案件上書き）」のように表示されます
- ストックの金額は**1ヶ月あたり**です
- 担当代理店／上位代理店の内訳が不要な場合は「合計」列だけ表示してください
- 収益情報の列は社内ユーザー（admin / staff）のみ表示されます

### 案件ごとの報酬・取り分の変更

案件詳細の「代理店支払手数料」タブで設定します。

| 項目 | 用途 |
|------|------|
| 収益確定日 | **支払明細書（締め）**での報酬の発生起点。営業ステータスが「収益確定」に変わると自動セットされます。誤設定の訂正や過去分の登録もここで行います（ダッシュボードの収益はこの日付を使いません） |
| 解約日 | ストック（毎月発生）の停止月 |
| 報酬の上書き | この案件だけ報酬率を変える場合 |
| 自社取り分の上書き | この案件だけ取り分を変える場合（例: 通常20%だがこの契約だけ15%） |

タブ下部に、保存済みの内容で計算した自社売上・報酬・粗利・粗利率が表示されます。

**注意**: 収益確定済みの案件の取り分を後から変更すると、その月の粗利が変わります。過去月の数字を確定させたい場合は変更前に確認してください。

### ポイント
- 「最終」「失注」ステータスの案件はデフォルトで非表示です。フィルターで該当ステータスを選択すると表示されます
- ピン機能: よく確認する案件を上部に固定できます

## 7. タスク管理

**画面**: サイドバー「タスク管理」

### マイタスクとグループボード
- **マイタスク**: 自分だけのタスク管理（他のボードの担当タスクとは独立）
- **グループボード**: チームで共有するタスクボード（全社・事業・チーム等、用途自由）

### ビュー切替
- **リスト**: 一覧表示（フィルター・ソート対応）
- **カンバン**: ステータス列ごとのカード表示（ドラッグ&ドロップ対応）
- **カレンダー**: 期限日ベースの月間カレンダー

### タスクの作成
1. 「タスク追加」をクリック（カンバンでは各列の「+」ボタン）
2. タイトルを入力
3. 必要に応じて設定:
   - 担当者（複数選択可、外部担当者はフリーテキストで追加）
   - 優先度（緊急・高・中・低）
   - 期限日
   - タグ
   - サブタスク・チェックリスト
   - 添付ファイル（ドラッグ&ドロップ or Ctrl+V で貼り付け可能、10MB/10ファイルまで）
4. 保存

### タスクの移動・コピー

タスク詳細パネルの右上にある `⋯`（アクションメニュー）から操作できます。

**ボードに移動**:
1. タスク詳細パネルの `⋯` をクリック
2. 「ボードに移動」を選択
3. 移動先を選択（マイタスク or グループボード）
4. タスクが移動先のボードに移動します

**タスクをコピー**:
1. タスク詳細パネルの `⋯` をクリック
2. 「タスクをコピー」を選択
3. タイトル末尾に「（コピー）」がついた複製タスクが作成されます

**ポイント**:
- コピーでは担当者・タグ・チェックリスト等が引き継がれます
- コピーではステータスは「未着手」にリセットされます
- サブタスクと添付ファイルはコピーされません
- ボード移動時、カンバン列はリセットされます（ボード間で列は共有されないため）

### カンバンの操作
- カードをドラッグ&ドロップで別の列に移動すると、タスクのステータスも自動的に更新されます
- 列自体もドラッグ&ドロップで順序変更可能
- 「自分のタスクを表示」トグルで自分の担当タスクのみ表示

## 8. プッシュ通知

### プッシュ通知とは

ブラウザやアプリを閉じていても、スマホやPCに通知が届く機能です。
以下のイベントでプッシュ通知が送信されます：

| イベント | 説明 |
|---------|------|
| 営業ステータス変更 | 案件のステータスが変更された時 |
| タスクアサイン | タスクに担当者として割り当てられた時 |
| タスク完了 | 担当タスクが完了した時 |
| タスク期限超過 | 担当タスクの期限が過ぎた時（日次cronジョブ） |
| 資料共有通知 | 管理者が資料・明細の通知を送信した時 |
| システム通知 | その他のシステム通知 |

### プッシュ通知の有効化 / 無効化

通知ポップオーバー上部の**トグルスイッチ**で切り替えます。

1. ヘッダー右上のベルアイコン🔔をクリック
2. 「プッシュ通知」の横にあるトグルスイッチをONにする
3. ブラウザの許可ダイアログで「許可」を選択
4. 以後、プッシュ通知が届くようになります

無効にする場合は、同じトグルスイッチをOFFにしてください。

### デバイス別の対応状況

| デバイス | ブラウザ | 条件 |
|---------|---------|------|
| **PC** | Chrome / Edge / Firefox | ブラウザで有効化するだけでOK |
| **Android** | Chrome | ブラウザで有効化するだけでOK（ホーム追加は任意） |
| **iPhone** | **Safariのみ** | **ホーム画面に追加が必須**（下記手順参照） |

> ⚠️ **iPhoneの注意点**: iPhone では Safari 以外のブラウザ（Chrome等）ではプッシュ通知が届きません。必ず Safari を使用してください。

### iPhoneでのホーム画面追加手順

1. **Safari** で管理システムのURLを開く
2. 画面下部の **共有ボタン**（□に↑のアイコン）をタップ
3. 「**ホーム画面に追加**」をタップ
4. 名前を確認して「追加」をタップ
5. **ホーム画面から** アプリアイコンをタップして起動
6. ベルアイコン → トグルスイッチをON → 「許可」

> iOS 16.4以降が必要です。

### 通知の管理

通知はベルアイコン🔔のポップオーバーから管理できます。

| 操作 | 方法 |
|------|------|
| 既読にする | 通知をクリック（関連画面に遷移） |
| すべて既読 | ヘッダーの「すべて既読」ボタン |
| 個別削除 | 通知にマウスを合わせて表示される**×ボタン**をクリック |
| すべて削除 | ヘッダーの「すべて削除」ボタン |

**ポイント**:
- 通知はDBに蓄積されます。不要な通知は削除してください
- 既読にしても通知は残ります（削除は別操作）
- 代理店ポータルでも同じ通知ベルが表示されます

### トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| トグルスイッチが表示されない | ブラウザがプッシュ通知に対応していない可能性があります |
| 「ブロックされています」と表示 | ブラウザの設定で通知を許可してください |
| iPhoneで通知が届かない | Safariでホーム画面に追加してから起動しているか確認してください |
| 複数デバイスで通知が届かない | 各デバイスで個別に「有効にする」操作が必要です |

## 10. テーブル共通操作

システム内の多くの一覧画面で使える共通操作です。

### テーブル表示設定（列設定モーダル）
テーブル右上の「列設定」ボタンから、3タブ構成の設定モーダルを開きます。

**基本設定タブ**:
- 表示件数を10/25/50/100件から選択

**列の表示・順序タブ**:
- 左側に表示中の列、右側に非表示の列が一覧表示されます
- 列名を検索バーでフィルター可能（多数の列がある場合に便利）
- チェックボックスで複数列を選択し「選択した列を非表示」で一括操作
- 表示中の列はドラッグ&ドロップで並び順を変更可能
- 非表示の列は目のアイコンで個別に表示に戻せます
- ピンアイコンで列を左固定できます

**ソート設定タブ**:
- 「ソートを追加」でソート対象列を選択
- 各ソートに優先度番号バッジ（1, 2, 3...）が表示されます
- 昇順/降順の切替、↑↓で優先度の並び替え、×で削除が可能

**保存の仕組み**:
- 「保存」ボタンで設定が確定します。「キャンセル」で変更を破棄できます
- 「デフォルトに戻す」で全設定をリセット（確認ダイアログ付き）
- アクティブビューがある場合、設定はビューにも自動保存されます

### テーブルヘッダー
- テーブルヘッダーはスクロール時も固定表示されます
- 列名をクリックするとソート（昇順→降順→解除）。複数列に対してソートでき、優先度が番号で表示されます
- カスタムフィールドのテキスト型は自然順ソート対応（"MO-1", "MO-2", "MO-11" の順に正しくソート）
- ヘッダー上のドラッグ&ドロップでも列並び替え可能（モーダル内のD&Dと同等）

### ビュー管理
- 「ビューを保存」: 現在の列設定・フィルター・ソート・表示件数を名前付きで保存
- タブで保存済みビューを素早く切替
- 「チームに共有」にチェックすると他ユーザーも利用可能（読み取り専用）
- 共有ビューは「自分のビューにコピー」でカスタマイズ可能

| AIアシスタントが使えない | 管理者がAPIキーを設定していない可能性があります。管理者に確認してください |
| ログインできない | パスワードが正しいか確認。解決しない場合は管理者に連絡 |
| CSVインポートでエラー | エラーレポートをDLして内容確認。顧客コードの重複や必須項目の未入力が多い原因です |
| 列の並びがおかしい | 列設定モーダルの「デフォルトに戻す」で順序をリセットしてください |
| プッシュ通知が届かない | ベルアイコンから有効化済みか確認。iPhoneはSafariでホーム追加が必須 |
| 通知がブロックされた | ブラウザ設定 → サイトの設定 → 通知 → 「許可」に変更 |
